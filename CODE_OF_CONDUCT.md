# Code of Conduct

## Our Standard

This project should remain a respectful, professional, and useful place to collaborate.

Participants are expected to:

- communicate respectfully and constructively
- focus criticism on ideas, code, and behavior rather than people
- respect different backgrounds, experience levels, and viewpoints
- avoid harassment, discrimination, threats, or deliberately disruptive behavior
- protect private or sensitive information shared during collaboration

Unacceptable behavior includes harassment, personal attacks, discriminatory language, intimidation, doxxing, sexual harassment, and repeated disruption after being asked to stop.

## Scope

This code applies to repository discussions, issues, pull requests, reviews, and other project spaces connected to Honest Online Learning.

## Enforcement

Maintainers may edit or remove inappropriate content and may temporarily or permanently restrict participation when necessary to protect the project and its contributors.

Serious concerns can be reported privately to the repository owner through the contact information on their GitHub profile.

## Attribution

This code of conduct is maintained specifically for this repository and may be updated as the project evolves.
